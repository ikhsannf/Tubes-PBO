# 🎬 movInfo – Java Web Application (JSP, Servlet, MySQL, Ant)

movInfo adalah aplikasi web berbasis Java yang dibangun menggunakan **Servlet**, **JSP**, dan **Ant (NetBeans)**.  
Aplikasi ini menyediakan fitur pengelolaan film, berita, favorit, dan like pada berita, dengan sistem login admin & pengguna.

---

## 🚀 Fitur Utama

### 👤 **Manajemen Akun**
- Login untuk admin dan pengguna
- Role-based access (admin & user)

### 🎥 **Film**
- Melihat daftar film
- Detail film
- Menambahkan film *(khusus admin)*
- Menandai film sebagai favorit (user)

### 📰 **Berita**
- Menampilkan berita terbaru
- Admin bisa menambah, edit, dan hapus berita
- Pengguna dapat memberikan **Like** pada berita

### ⭐ **Favorite**
- Pengguna dapat menandai film sebagai favorit
- Halaman khusus untuk daftar film favorit

### 👍 **Like Berita**
- Sistem like pada berita
- Prevent duplicate like (1 user hanya boleh 1 kali like per berita)
